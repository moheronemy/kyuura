# kyuura — 旧裏ポケモンカードの資料

初期のポケモンカードゲーム、いわゆる「旧裏」（1996〜2001年の旧デザイン裏面のカード）のカードリストとルールをまとめる資料集です。
日本版（メディアファクトリー発売）と英語版（Wizards of the Coast 発売）の違いを明らかにすることを主な目的にしています。

> 作業中です。ルール関係の文書は調査結果を反映して追加します。
