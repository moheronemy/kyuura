# 利用者が採用したとりかえっこプリーズの所有者の簡略仕様（エンジン固有の扱い。2026-10-31 の記録）

kyuura-engine で、とりかえっこプリーズ（PR1-027）で交換したカードの対戦中の所有者を決めるという、**利用者が採用した簡略仕様**の記録です。原典の調査・公式の裁定・エラッタ・最新の説明ではありません。kyuura のカードデータ（印刷の文面の転記）と研究の記録（裁定・論点）は変えていません。

この記録は、同じ日の [利用者が指定したプロモ 3 枚の簡略化](engine-user-promo-simplifications.md)（_のピカチュウ・ハマちゃんのヤドキング）とは別の指定です。あちらの内容はこの記録で変えていません。

## 3. 採用された簡略仕様

この章の「所有者」は、エンジンの対戦の中の所有者（kyuura の研究の語では「持ち主」。p.312・p.323 の「持ち主」に当たるもの）です。

1. **交換が成立した時点で、交換された 2 枚それぞれの対戦中の所有者を、受け取ったプレイヤーへ変更する。** 片方だけを変更せず、交換の完了と一体で扱う。
2. 以後その対戦中は、新しい所有者を通常の所有者として一貫して使う。場に出す、つける、進化に使う、トラッシュする、山札へ戻す、きぜつしたときのサイドなどを、この所有者で処理する。
3. 元のデッキ・物理的な出所の記録、カード id・uid を、所有者の変更と混同しない。出所の記録は保持し、実物の所有権が変わったことにはしない。
4. 交換を断られた（オーケーでない）場合は、所有者を変更しない。既存の手順どおり、使ったプレイヤーが山札から 2 枚引く。交換したカードではない「とりかえっこプリーズ」自身の所有者は、この交換では変えない。
5. 再交換（交換で受け取ったカードが、のちのとりかえっこプリーズでふたたび交換される場合）が成立したときも、同じ規則で受け取ったプレイヤーを新しい所有者にする。過去の所有者へ自動的に戻す隠れた特例を設けない。
6. 同名 4 枚などのデッキ構築の制限を、交換のたびに再適用して拒否する規則は追加しない。対戦開始時のデッキの検査とは区別する。

範囲:

- これは対戦エンジンの中のルールです。利用者どうしが実物のカードを売買・譲渡したことを記録する機能ではありません（p.293 の解説の「本当にとりかえてしまうか、ゲームの間だけなのか」は対戦の外の取り決めと読む CR-SWAP-PLEASE-REAL-TRADE-SEPARATE のまま。この仕様はその取り決めを決めない）。
- 将来の新しい対戦の初期所有者を、前の対戦の交換で自動的に変更する仕様でもありません。所有者の変更はその対戦の中だけです。

## 4. 原典上の未解決との違い

- **UQ-SWAP-PLEASE-OWNERSHIP は、歴史資料上は未解決のまま（`UNRESOLVED`）です。** 問い・分類・出典・監査・事例は変えていません。エンジンが採用する読み方が決まったことと、公式の裁定が判明したことは別です。
- 研究の記録の 5.2 の比べでは、この仕様は**読み B**（交換で受け取ったプレイヤーが持ち主になる）に当たる処理です。読み B が原典で決まったとはしていません。読み A（もとのデッキのプレイヤーのまま）を否定する資料も見つかっていません。
- 研究の記録で読みにより結果が変わるとした事例は、この仕様では次のように処理します（エンジンの仕様の説明で、原典の結論ではない）。

| 事例（研究の記録 5.2・UQ-SWAP-PLEASE-OWNERSHIP の notes） | この仕様での処理 |
|---|---|
| 受け取ったポケモンを出してきぜつ | 所有者は受け取ったプレイヤー。サイドを取るのはその相手（p.323 の「相手側」と「持ち主でない」が同じプレイヤーになる） |
| 受け取ったトレーナー・エネルギーをトラッシュ | 受け取ったプレイヤーのトラッシュ |
| 山札にもどす | 受け取ったプレイヤーの山札 |
| 進化に使う・エネルギー・どうぐをつける | 受け取ったプレイヤーのカードとして使い、きぜつしたときも受け取ったプレイヤーのトラッシュ |

- 事例に挙がっているヤドキング neo1-049 の［ちえくらべ］・錯乱ジム PMCG5-087 との組み合わせを、この仕様で受け付けると決めたものではありません。それぞれ UQ-MIND-GAMES-TRAINER-STEP・UQ-MIND-GAMES-OPTIONAL・UQ-CHAOS-GYM-BORROWED-TURN などの別の論点が残ります。

## 5. この指定で決めていないこと
