# kyuura-engine への引き継ぎ（v0.120 のあと。次の便のカードの文面と進化データ）

kyuura-engine の v0.120 のあとの便で、優先A・優先B の 17 枚を扱うときに、kyuura の側で整えたことと、エンジンで見直すことです。調査の記録は [次の便のカードの文面と進化データの調査](next-engine-text-evolution-research.md) にあります。kyuura の記録は研究の資料で、エンジンの設計を kyuura の裁定として記録していません。kyuura を更新することと、エンジンの写しの元を上げる移行・カードの登録は別の作業です。

## 1. 前提

- kyuura: 作業ブランチ `claude/next-engine-text-evolution-research`（基点 `e519b99e2adcc6c2cd0998569ae5ee1101de6e89`）。
- エンジンの写しの元: 公開済みの v0.119（`fd5395514f225f71d831690ae1e07b915e03d38d`）の `scripts/extract_kyuura_cards.py` の `KYUURA_COMMIT` は `e519b99`（この作業の基点）。エンジンはまだこの作業の kyuura を参照していない。
- kyuura の登録表の写しは固定した v0.113（`2d113b5`。登録 1,250）のままで、`data/engine_targets.json` の分類もこの写しによる。v0.119 は比べるためだけに読んだ（登録 1,322。kyuura の `data/` には写していない）。実装中の v0.120 は読んでいない・取り込んでいない（登録表・停止の数・テストの結果を作っていない）。

## 4. ピカチュウのなきごえ

- 処理は最新の説明（p.127）「次の相手の番、このワザを受けた相手は、このカードにダメージを与えるとき、そのダメージが「-10」される。」にしたがう（CR-PIKACHU-GROWL-LATEST。CONFIRMED）。印刷の文面「次の相手の番でうけるダメージを10へらすことができる。」の、減らすかを選べる・だれのダメージでも減る読み方をとらない。
- エンジン v0.119 の IP1-040 の実装 `ReduceDamageToSelfNextOpponentTurn` は、受けた相手に与える持続する効果で p.321 の 2 段階で引く（エンジンの docstring）。kyuura の CR-PIKACHU-GROWL-OPPONENT-EFFECT（SUPPORTED。段階は推論）と同じ読み方。PR1-001・PR1-003・PR1-017 に同じ実装を使うなら、印刷の文面と実装がしたがう文面が違うので、エンジンの最新の説明の仕組み（`play_text_ja`・`source`）で登録する: 出典は P43 p.127、当てはめは LD-PR1-003-ATK0（図版）・LD-PR1-001-ATK0（見出しの配布）・LD-PR1-017-ATK0（見出しの配布。配布の特定は推論）。v0.119 の文面の照合（`GROWL_TEXTS`）にある 3 つの文面は、どれも「このワザを受けた相手」を書く新しい形で、PR1 の 3 枚の印刷の文面（古い書き方）は入っていない（v0.119 の木で確かめた）。
- 3 枚のうち、図版で照合したのは PR1-003 だけ。PR1-017 の配布（「トヨタオートキャンペーン」プレゼントカード）は推論で、確かめられていない。
- 決まらないこと: 受けた相手がワザ以外でこのカードに与えるダメージ・ベンチのこのカードへのダメージ（UQ-GROWL-NON-ATTACK-DAMAGE。未解決）。エンジン v0.119 は、効果を与えたポケモンが控えにいるときの控えへのダメージを、v0.34 の NK5 と同じ確かめで止めている（エンジンの docstring）。原典で決まらない場合は止める扱いのままにすること。

## 5. ヤドランのおおいびき

- ねむり状態のとき: おおいびきは宣言でき、30 ダメージ（CR-SLOWBRO-SNORE-WHILE-ASLEEP。CONFIRMED）。エンジンのワザ・にげるの制限（`_require_not_asleep_or_paralyzed`）は、このワザだけを例外にする形が要る（ほかのワザ・にげるは制限したまま。CR-SLOWBRO-SNORE-ONLY-THIS-ATTACK）。ねむりのコインはポケモンチェックでいつもどおり投げる。
- ねむり状態でないとき: 宣言でき（エネルギーはいる）、失敗する。失敗してもワザを使ったことになり、番は終わる（CR-SLOWBRO-SNORE-AWAKE-FAILS。CONFIRMED）。「宣言できない」として不正なコマンドにしない。起きているのに 30 ダメージを与えない。
- 失敗が決まるのは説明を処理する p.309 の手順 6 で、こんらん状態なら先に手順 5 のこんらんのコインを投げる（SUPPORTED。手順の位置は推論）。
- 決まらないこと: ほかのカードのワザとしておおいびきを使う場合（UQ-COPIED-ATTACK の事例）。おおあくび（自分と相手をねむり状態にする）も未登録。

## 6. ボロのつりざお

- 効果文は「…すべて「うら」なら「トレーナーカード」を、あなたのトラッシュから1枚選び出し、…」（直した値）。2 枚とも「おもて」→ ポケモンのカード 1 枚、2 枚とも「うら」→ トレーナーカード 1 枚、1 枚ずつ → 何も加えない。使ったカードはトラッシュする（CR-BORO-ROD-COIN-RESULTS。CONFIRMED）。
- 「ポケモンのカード」はベイビィポケモンカード・たねポケモンカード・進化カード（CR-BORO-ROD-POKEMON-CARDS。CONFIRMED。p.313 は既存の転記）。
- 決まらないこと: トラッシュに選べるカードがないときに使えるか・コインを投げるか（UQ-CARD-USE-WITHOUT-TARGET。未解決。成功を仮定せずに止めること）、トラッシュのなにかの化石などの扱い、枚数不足の一般の問い（UQ-STATED-COUNT-SHORT）。
