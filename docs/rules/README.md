# ルール資料

旧裏期のルールを、日本版と英語版（WotC 版）に分けてまとめています。

| 文書 | 内容 |
|---|---|
| [日米のルールの違い](differences.md) | **まずこれ。** ルールの違いだけを項目ごとに比べた専用ページ。よくある誤解の整理つき。データは `data/rule_differences.json` |
| [日本版のルールと変遷](japanese.md) | メディアファクトリー版。ルールブック第1版〜第5版での変更点、公式大会のルール |
| [英語版（WotC 版）のルール](wotc.md) | Wizards of the Coast 版（1999〜2003年）。2003年の Pokémon USA への移行時の変更も参考に記載 |

ルール以外の日英の違いは、カードリストの側にあります。

- [カードの日英の違い](../cards/card-differences.md): 文面の意味・エラッタ・表記
- [収録内容・製品の違い](../cards/set-differences.md): 弾の対応、印刷、裏面

## 確度の表記

各項目の末尾に、その記述をどこまで確かめられたかを付けています。

| 表記 | 意味 |
|---|---|
| **確実** | 公式資料、または互いに独立した二次資料 2 件以上で一致している |
| **有力** | 信頼できそうな二次資料 1 件だけで確認した |
| **未確認** | 確認できていない、または資料どうしが食い違っている |

## 調べ方と限界

- この資料は、ウェブ検索の結果（検索エンジンが返す要約と抜粋）をもとに作りました。作成環境の制約で、参照先のページを直接開いて読むことはできていません。ルールブックの現物や PDF との照合もしていません。
- このため、本文中の「」内の引用は検索結果に出てきた文言で、原文と一字一句同じとは限りません。
- 日本版の主な情報源は、ファンによる「ポケモンカード旧裏面＠研究・考察 Wiki*」（以下「旧裏 wiki」）の「当時のルール」ページです。このページは『ポケモンカードゲーム オフィシャルブック2000』『めざせ！ポケモンカードマスター』『ポケモンカード トレーナーズ vol.1』やファンクラブ会報を出典に挙げています。
- 英語版の主な情報源は、Pojo.com に転載された WotC のルールブック（Basic／Expert Rules、Neo Genesis の追加ルール、Advanced Rulebook Version 8・9）と、Jason Klaczynski 氏のサイト（jklaczpokemon.com）などです。
- 確度が「未確認」の項目は、一般的な知識で穴埋めせず、未確認のまま残しています。
