- [カードの日英の違い](../cards/card-differences.md): 文面の意味・エラッタ・表記

当時の雑誌・書籍のスキャンで確認したページは [印刷物の照合記録](../printed-sources.md) にまとめています（生成: `scripts/build_rule_history.py`）。

## 確度の表記

各項目の末尾に、その記述をどこまで確かめられたかを付けています。

| 表記 | 意味 |
|---|---|
| **確実** | 公式資料、または互いに独立した二次資料 2 件以上で一致している |
| **有力** | 信頼できそうな二次資料 1 件だけで確認した |
| **未確認** | 確認できていない、または資料どうしが食い違っている |

## 調べ方と限界

- 2026年10月に加えた 3 つの文書（混合ルール・新ガルーラルール・エラッタの履歴）では、なぞのばしょの記事と Bulbapedia のページ（MediaWiki の API）を直接読み、カードの文面は pcg-search の画像で確かめました。その後の追加の検証で、公式サイトの「ポケモンカードｅシリーズ以前の特殊能力 Ｑ＆Ａ」[P10] を Internet Archive に保存された写しで原文のまま確認し、旧裏 wiki の「当時のルール」[J1]・「旧裏の歴史」[J6] を Internet Archive の写しで、note の記事 [J30][J31][J32] を直接読みました。さらに、公式サイトの殿堂入りカードの一覧・ミックスデッキルール・新ガルーラルール・2002年と 2003年の大会のレギュレーション・『トレーナーズ』の発売告知・「プレイルール」（P15〜P23、P28）を Internet Archive の写しで確認しました。当時の印刷物は、Elite Fourum のスレッドで公開されたスキャン [J37] で、1996年の発売元のガイドブック（P29。第4刷）、『ポケモンカード・ファンクラブ』Vol.1（P30。第3刷）・Vol.3〜5（P31、P1、P2）、『めざせ! ポケモンカードマスター』（P34）、『トレーナーズ』Vol.1・2・6（P32、P33、P3）と Vol.10〜16・18〜21（P4〜P9、P13、P24〜P27）を確認しました。どれもスキャンで文面を読んだもので、印刷物の実物は確認していません。版ごとのルールブック・遊びかた説明書そのもの、『オフィシャルブック2000』、会報 Vol.2、『トレーナーズ』Vol.3〜5・7〜9・17 の本文は確認できていません（[出典と確認状況](../sources.md)、[印刷物の照合記録](../printed-sources.md)）。検索結果の要約だけで確かめたものは本文でそう明記しています。
- 以下は、最初に作った文書（日本版・英語版のルール、日米の違い）についての説明です。
- この資料は、ウェブ検索の結果（検索エンジンが返す要約と抜粋）をもとに作りました。作成環境の制約で、参照先のページを直接開いて読むことはできていません。ルールブックの現物や PDF との照合もしていません。
- このため、本文中の「」内の引用は検索結果に出てきた文言で、原文と一字一句同じとは限りません。
- 日本版の主な情報源は、ファンによる「ポケモンカード旧裏面＠研究・考察 Wiki*」（以下「旧裏 wiki」）の「当時のルール」ページです。このページは『ポケモンカードゲーム オフィシャルブック2000』『めざせ！ポケモンカードマスター』『ポケモンカード トレーナーズ vol.1』やファンクラブ会報を出典に挙げています。
