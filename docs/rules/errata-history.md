# カードの文面の変更とエラッタの履歴

<!-- このファイルは scripts/build_rule_history.py が data/rule_history.json から生成しています。直接編集しないでください。 -->

旧裏期（1996〜2001年）のカードについて、印刷された文面の変更、公式エラッタ、ルールによる読み替えを記録します。2001〜2003年の旧裏・新裏の混合ルールは [旧裏・新裏の混合ルール](mixed-2002.md)、出典の記号は [出典と確認状況](../sources.md) を参照してください。

<a id="kinds"></a>

## 3 つの区別

| 区分 | 意味 | 例 |
|---|---|---|
| 印刷テキストの変更 | 再録や新しい版に、違う文面が印刷されたこと。**それだけでは古い版の扱いは変わらない** | ジムデッキの再録の書き換え（[再録カードの対応付け](../cards/reprints.md)） |
| 公式エラッタ | 印刷された版にかかわらず、別の文面で使うよう公式に指定されたこと | エネルギー回収を基本エネルギーだけにする（1998年） |
| ルール変更・裁定 | カードの文面は変わらないが、ルールや裁定で効果の扱いが変わること | 旧裏の特殊能力をポケパワー・ポケボディーとして扱う（2002年） |

- 再録で文面が変わったことだけを根拠に、古い版にも同じエラッタが出たとはしていません。エラッタの告知を確認できないものは「未確認」としています。
- 日本版（メディアファクトリー／ポケモン）と英語版（WotC）の扱いは分けて書いています。英語版だけのエラッタ・禁止は、日本版には当てはまりません。

## 根拠の種類と確度

| 根拠の種類 | 意味 |
|---|---|
| original | 当時の公式資料の原本を直接確認した |
| card_image | カードの画像（pcg-search・なぞのばしょの掲載画像）で印刷された文面を確認した |
| official_later | 後年の公式資料（公式サイトの年表、2016年のクラシックレギュレーションなど） |
| secondary_direct | 二次資料（ファンサイト・Wiki）の本文を直接読んだ。cites はその資料が挙げている当時の公式資料（原本は未確認） |
| search_summary | 検索エンジンの要約・抜粋だけで確認した（本文は未確認。文言は原文と同じとは限らない） |

表の短い名前（各項目の「根拠」で使用）: original = 原本、card_image = カードの画像、official_later = 後年の公式資料、secondary_direct = 二次資料（本文を確認）、search_summary = 検索結果の要約のみ。

| 確度 | 意味 |
|---|---|
| 確実 | 公式資料（カードの画像を含む）、または互いに独立した資料 2 件以上（本文を直接読んだもの）で一致 |
| 有力 | 本文を直接読んだ二次資料 1 件、または検索結果の要約で独立した 2 件が一致 |
| 未確認 | 検索結果の要約 1 件だけ、資料どうしが食い違う、または確認できていない |

- 今回の調査では、当時の公式資料（ルールブック・『トレーナーズ』・ファンクラブ会報・公式サイト）の原本は確認できていません。二次資料が挙げている当時の資料は [P1] などの記号で示しています。

### MIX-POWER-ERRATA: 旧裏・neo の特殊能力を、ポケパワーかポケボディーとして扱う

- 地域: 日本版　区分: 公式エラッタ（印刷された版にかかわらず、別の文面で使うよう公式に指定されたもの）
- 公表: 2002-05-24（公式サイトの Q&A。日付は Bulbapedia の引用による）
- 適用・印刷の開始: 未確認
- 対象の大会・商品: 公式サイト「ポケモンカードeシリーズ以前の特殊能力 Q&A」（EV-2002-QA-POWERS）
- 変更前: 印刷どおり「特殊能力」
- 変更後: ここに挙げたカードはポケボディー、それ以外のカードの特殊能力はすべてポケパワーとして扱う
- Bulbapedia は、日本だけのエラッタとして、ポケボディーになるカードの一覧を挙げ、それ以外はポケパワーになったとする。出典は公式サイトの「ポケモンカードeシリーズ以前の特殊能力 Q&A」（2002-05-24。Internet Archive の 2005-10-18 の保存）[X52]。
- ポケボディーになったのは、宣言せずに常にはたらく効果（使うかどうかを選べない効果）のもの [X52]。
- 特殊能力に作用する効果（ブビィの「モクモク」など）は、ポケパワーとポケボディーの両方に作用する、という裁定も挙げられている [X52]。
- 英語版ではこのエラッタは出ていない。ポケパワーまたはポケボディーの片方だけに作用する効果は、古いポケモンパワーには作用しない（WotC、2003-05-22）。両方に作用する効果は作用する（TPCi、2003-10-16）[X52]。
- 現代の旧裏対戦の店舗ルールの解説には、「ねむり・マヒ・こんらんのとき使えない」と書かれた特殊能力は、どく・やけどを含むすべての特殊状態で使えない、とするものがある（検索結果の要約）[J31]。当時の公式の根拠は未確認（英語版では WotC が 2002-01-17 に同じ趣旨のルール変更をしている [X52]）。
- 根拠:
  - [X52] Pokémon Power split（In Japan only）（当時の資料: [P10]） — 二次資料（本文を確認）
  - [J31] 店舗ルールでの読み替えの説明 — 検索結果の要約のみ
