# カードの文面の変更とエラッタの履歴

<!-- このファイルは scripts/build_rule_history.py が data/rule_history.json から生成しています。直接編集しないでください。 -->

旧裏期（1996〜2001年）のカードについて、印刷された文面の変更、公式エラッタ、ルールによる読み替えを記録します。2001〜2003年の旧裏・新裏の混合ルールは [旧裏・新裏の混合ルール](mixed-2002.md)、出典の記号は [出典と確認状況](../sources.md) を参照してください。

<a id="kinds"></a>

## 3 つの区別

| 区分 | 意味 | 例 |
|---|---|---|
| 印刷テキストの変更 | 再録や新しい版に、違う文面が印刷されたこと。**それだけでは古い版の扱いは変わらない** | ジムデッキの再録の書き換え（[再録カードの対応付け](../cards/reprints.md)） |
| 公式エラッタ | 印刷された版にかかわらず、別の文面で使うよう公式に指定されたこと | エネルギー回収を基本エネルギーだけにする（1998年） |
| ルール変更・裁定 | カードの文面は変わらないが、ルールや裁定で効果の扱いが変わること | 旧裏の特殊能力をポケパワー・ポケボディーとして扱う（2002年） |

- 再録で文面が変わったことだけを根拠に、古い版にも同じエラッタが出たとはしていません。エラッタの告知を確認できないものは「未確認」としています。
- 日本版（メディアファクトリー／ポケモン）と英語版（WotC）の扱いは分けて書いています。英語版だけのエラッタ・禁止は、日本版には当てはまりません。

## 根拠の種類と確度

| 根拠の種類 | 意味 |
|---|---|
| original | 当時の公式資料の原本を直接確認した |
| archived_official | 当時の公式サイトのページを、Internet Archive（Wayback Machine）に保存された写しで直接読んだ（保存された時点の内容。印刷物の原本ではない） |
| scan_image | 当時の印刷物（雑誌など）のページの写真・スキャンを見て文面を確認した（原本そのものではない。号数・ページは画像の表示と掲載元の説明による） |
| card_image | カードの画像（pcg-search・なぞのばしょの掲載画像）で印刷された文面を確認した |
| official_later | 後年の公式資料（公式サイトの年表、2016年のクラシックレギュレーションなど） |
| secondary_direct | 二次資料（ファンサイト・Wiki）の本文を直接読んだ。cites はその資料が挙げている当時の公式資料（原本は未確認） |
| search_summary | 検索エンジンの要約・抜粋だけで確認した（本文は未確認。文言は原文と同じとは限らない） |

表の短い名前（各項目の「根拠」で使用）: original = 原本、archived_official = 公式ページの保存版（原文を確認）、scan_image = 印刷物の写真（文面を確認）、card_image = カードの画像、official_later = 後年の公式資料、secondary_direct = 二次資料（本文を確認）、search_summary = 検索結果の要約のみ。

| 確度 | 意味 |
|---|---|
| 確実 | 公式資料（カードの画像を含む）、または互いに独立した資料 2 件以上（本文を直接読んだもの）で一致 |
| 有力 | 本文を直接読んだ二次資料 1 件、または検索結果の要約で独立した 2 件が一致 |
| 未確認 | 検索結果の要約 1 件だけ、資料どうしが食い違う、または確認できていない |

- 当時の公式資料のうち原文を確認できたのは、公式サイトのページ（[P10]、[P15]〜[P23]、[P28]。Internet Archive に保存された写し）と、『トレーナーズ』Vol.10〜16・18〜21 と 1996年のガイドブックの誌面（[P4]〜[P9]、[P13]、[P24]〜[P27]、[P29]。[J37] のスキャン）です。ルールブック・ファンクラブ会報の原本と、『トレーナーズ』Vol.9 以前・Vol.17 は確認できていません。二次資料が挙げている当時の資料は [P1] などの記号で示しています。

- 地域: 日本版　区分: 印刷テキストの変更（再録・新しい版に違う文面が印刷されたこと。それだけでは古い版へのエラッタを意味しない）
