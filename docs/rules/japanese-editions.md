# 日本版のルールの版ごとの比較（1996〜1999年）

<!-- このファイルは scripts/build_rule_history.py が data/rule_history.json の jp_editions・jp_edition_matrix から生成しています。直接編集しないでください。 -->

旧裏期の日本版のルールを、版ごと・項目ごとに並べた表です。ルールの説明と資料の食い違いは [日本版のルールと変遷](japanese.md)、英語版との比較は [日米のルールの違い](differences.md)、出典の記号は [出典と確認状況](../sources.md)、スキャンで確認した誌面のページは [印刷物の照合記録](../printed-sources.md) を参照してください。

- 版ごとの文書（ルールブック・遊びかた説明書）の原文は、どの版も確認できていません。表の内容は、各版の時期の公式の雑誌・書籍の説明（スキャン）と二次資料によります。
- 原文や当時の説明で確認できなかったマスは「未確認」です。ほかの版の内容から推測して埋めていません。
- 「公式ルール」「ルールブック」「遊びかた説明書」は資料によって呼び方が違います。1997年の会報は、詳しい「公式ルール」は書籍（『大人にもわかるポケモンカード戦略』）に載せ、スターターパックの「遊びかた説明書」は「順次改定される予定」と書いています [P31]。版の番号が同じ文書の系列を指すかは確認できていません。
- 発売元のガイドブック [P29] の「公式ルール」は、基本の遊びかたとは別の追加ルールとして書かれています。公式大会の大会専用ルールも、基本ルールとは別のものです。

## 項目ごとの補足

<a id="deck"></a>

### デッキの枚数と同じ名前のカード

- 第4版の列は 1998年2月の会報 Vol.4 の Q&A による [P1]。ルールブックの文面ではない。
- スターターパックは 60 枚のデッキとして使える内容だった [P34]。1999年夏の公式大会の規定は「デッキに入れる60枚のカードのうち、同じ名前のカードは4枚まで」[P33]。

<a id="mulligan"></a>

### たねポケモンがいない場合（引き直し）

- 英語版との比較: [日米のルールの違い](differences.md#mulligan)
- 発売元のガイドブック [P29] は、たねポケモンがないときは手札を山札にもどして切り直し、7 枚引き直すとだけ書く（回数・相手の補償の記載なし）。
- 1998年のガルーラルール（特別ルール）は取り直し 2 回まで [P2]。

<a id="setup_bench"></a>

### 対戦準備でベンチに出せるポケモン

- 英語版との比較: [日米のルールの違い](differences.md#setup_bench)
- 発売元のガイドブック [P29]（1996年11月初版、確認したのは 1997年8月の第4刷）は、基本の手順ではバトル場に 1 枚置くだけで、慣れてから使う「公式ルール」として「控えとなるポケモンカードを1枚選んで、裏にしてベンチに置きます」（一発負けをふせぐため）とする。
- 1998年のガルーラルール（特別ルール）も、最初に出せるのは対戦ポケモン 1 匹と控えポケモン 1 匹 [P2]。第2〜4版のルールの文面は未確認。

<a id="first_player"></a>

### 先攻・後攻の決め方

- 英語版との比較: [日米のルールの違い](differences.md#first_player)
- ルールブックの文面はどの版も未確認。
- 発売元のガイドブック [P29]:「ジャンケンをして、先攻、後攻を決めます。」1998年のガルーラルール [P2] と 2002年の公式サイトのプレイルール [P23] もジャンケン。コインとする英語資料 [X1] と食い違う。

<a id="first_turn_draw"></a>

### 先攻の最初の番に山札を引けるか

- 英語版との比較: [日米のルールの違い](differences.md#first_turn_draw)
- 発売元のガイドブック [P29] は、基本の遊びかたでは毎番の最初に必ず 1 枚引くとし、慣れてから使う「公式ルール」に「先攻のプレイヤーは最初の番だけ、山札から1枚のカードを引かずに、ゲームを開始します」と書く。第2・3版の列は、このガイドブックがどの版にもとづくかわからないので未確認とした。
- 「1999年5月から先攻は最初の番に引かなくなった」とする英語の掲示板 [X13] は、『トレーナーズ』Vol.1 の内容と逆。
- 公式大会: 1999年夏のチャレンジロードの誌面のレギュレーションには先攻のドローの規定はない [P33]。2001年夏のバトル★ネオ サマーロードは大会専用ルールで引かない [P13]。
