# 英語版のみに見られるカード（日本の拡張パック未収録）

英語版（WotC）の各セットに収録されているが、日本の旧裏拡張パック 10 弾のどれにも対応カードが見つからないもの。
基本エネルギーは除外。

「日本での初出」は、拡張パック以外の商品（ジムデッキ、拡張シート、プレミアムファイル、プロモなど）の調査から、同じカードが日本で最初に出た商品を付けたものです（[拡張パック以外の商品](other-products.md)）。
