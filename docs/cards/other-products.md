# 拡張パック以外の商品

<!-- このファイルは scripts/build_other_products.py が data/ja_text_pcgsearch.json と data/curation/other_products.json から生成しています。直接編集しないでください。 -->

旧裏期に日本で出た、拡張パック 10 弾以外の商品のカードをまとめたページ群です。
対戦に使うカードは `data/cards.json`・`data/cards.csv` に、商品の記号の id（例 `GD1-009`）で収録しています（`product_group` が `expansion_pack` 以外の記録）。pcg-search の転記そのものは `data/ja_text_pcgsearch.json`、元の項目（カードページ）ごとの行き先（記録・番号違いのまとめ・対戦のカードでない項目）と商品の構成は [`data/product_items.json`](../../data/product_items.json)、商品をまたいだ同じカードの組は [`data/same_card_groups.json`](../../data/same_card_groups.json) にあります。

- カードの欄は、ポケモンカード 旧シリーズ検索（pcg-search.com）[N3] の転記です。進化元・にげるの一部は、同じサイトのカードページを読み直して確かめました（`data/pcgsearch_page_checks.json`。2026-10-19）。
- 商品の情報（発売日・構成・英語版の配布など）は、主に Bulbapedia [X30][X31][X41]〜[X48] によります（MediaWiki の API でページの原文を取得して確認）。
- 確度（確実／有力／未確認）と出典の記号は [出典と確認状況](../sources.md) を参照。

## 収録していない商品・範囲（わかっているもの）

23 の商品で旧裏期の商品をすべて収録できたとは言えません。わかっている範囲で、収録していないもの・確かめていないものを挙げます。

| 対象 | 根拠 | 扱い・不足 |
|---|---|---|
| pcg-search の「第1弾 スターターパック」（6 ページ。1st1s001〜1st1s006、基本エネルギー 6 種） | pcg-search のカードリスト（card_list.php。2026-10-19 に読み直し、取り込んだ 23 の商品の欄が前の取得と同じことを確かめた） | 拡張パックの記録 PMCG1-097〜PMCG1-102（収録商品に「スターターパック」）として収録済み。スターターパックのページは読んでおらず、ページとの対応づけ（source_ids.pcg_search）はしていない。スターターパックのほかのカードは拡張パック第1弾と同じカードとして扱っている（data/cards.json の jp_products） |
| pcg-search の「ポケモンカードGB 専用カード」（18 ページ）・「ポケモンカードGB2 GR団参上! 専用カード」（30 ページ） | pcg-search のカードリスト（2026-10-19） | ゲームボーイのソフトの中だけのカードで、印刷されたカードではないので収録しない（対象外）。GB の購入特典などで印刷されたカードはプロモ（PR1）にある |
| pcg-search の旧裏・neo の欄（/card/1st/・/card/neo/）のうち、ここにない欄 | pcg-search のカードリスト（2026-10-19） | ない。旧裏・neo の欄は、拡張パック 10 弾・neo の拡張パック 4 弾（拡張パックとして別に扱う範囲）・第1弾 スターターパック・取り込んだ 23 の商品だけ |
| ポケモンカードVS・ポケモンカード★web・それ以降のシリーズ（e・ADV など） | pcg-search のカードリストでは neo のプロモのあとの欄 | 新裏の別のシリーズなので対象外（今回の範囲を広げない） |
| pcg-search のカードリストにない旧裏期の商品・配布物 | なし（調べていない） | 23 の商品で旧裏期の商品をすべて収録できたとは言えない。プロモの一覧は pcg-search の「プロモ」の欄の範囲で、配布物の網羅は確かめていない（docs/cards/products/promos.md の「まだ確認できていないこと」） |

英語版にあって日本の拡張パックにないカードの、日本での初出は [英語版のみに見られるカード](english-only.md) にあります。
商品をまたいだ同じカード（再録）の判定のしかたと点検の結果は [再録カードの対応付け](reprints.md) にあります。

## まだ確認できていないこと

- 青版の「化石の発掘」「月の石」のレアリティマークの有無（pcg-search と Bulbapedia で食い違い）
