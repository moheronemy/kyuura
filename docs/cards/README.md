# カードリストの見かた

旧裏（きゅううら）期に日本で発売された拡張パック 10 弾のカードリストです。拡張パック以外の商品（拡張シート・サザンアイランド・ポケモンジム・クイックスターターギフト・イントロパック・neo プレミアムファイル・プロモ）は [拡張パック以外の商品](other-products.md) にあり、`data/cards.json` にも記録（id は `GD1-009` のような商品の記号の形）があります。
各弾のページは 2 部構成です。

- **カード一覧**: 日本版の収録カードを 1 行 1 枚で並べ、対応する英語版（WotC 版）のカードを横に置いた表。
- **カード詳細**: カードごとに、進化・タイプ・HP・弱点・抵抗力・にげるコストと、ポケモンパワー・ワザ（エネルギー・ダメージ・効果文）、トレーナー・特殊エネルギーの効果文を載せたもの。

同じ内容は構造化データ `data/cards.json` にもあります（[スキーマ](../data-schema.md)）。

## 列の意味

| 列 | 内容 |
|---|---|
| No. | このリスト内の通し番号。旧裏カードにはコレクター番号（「1/102」のような番号）が印刷されていないため、並び順は出典データ（TCGdex）に従っています。カード上の番号ではありません。 |
| 日本語名 | 日本版のカード名。下の「日本語名の根拠」を参照。 |
| 種類 | ポケモン／トレーナー（スタジアム、ポケモンのどうぐ などの下位区分つき）／基本エネルギー／特殊エネルギー |
| タイプ・進化・HP | 英語版データの値です（カード詳細の弱点・抵抗力・にげるコスト・ワザも同じ）。日本版と英語版で同じと考えていますが、カードごとに日本版の現物と照合したわけではありません。 |
| レア | 日本版のレアリティ。● コモン、◆ アンコモン、★ レア、★キラ ホロ（キラ）レア、特殊 = 通常の3段階に当てはまらないもの（出典データ上の Secret Rare など）。 |
| 英語版（WotC） | 対応する英語版カードの名前と、セット名・カード番号。同じセットにホロ版とノーマル版の両方がある場合は番号を「・」でつないでいます。 |
| ⚠ | 英語版では、この弾の主な対応セットとは別のセットに入ったカード。 |
| 備考 | 「日英の違い」は[カードの日英の違い](card-differences.md)に載っているカード。「再録」は同じカードが英語版の別セットにも入っていることを示します（略号は下表）。 |

英語版セットの略号: BS = Base Set、JU = Jungle、FO = Fossil、BS2 = Base Set 2、TR = Team Rocket、G1 = Gym Heroes、G2 = Gym Challenge、N1〜N4 = Neo Genesis／Discovery／Revelation／Destiny、LC = Legendary Collection、SI = Southern Islands、Promo = Wizards Black Star Promos。

## 日本語名の根拠

- **ポケモンのカード名**: 対応する英語版カードの図鑑番号から、公式の日本語種族名を引いて組み立てています。
  - 接頭辞の付け方:
    - ジムリーダーのポケモン: 「タケシの」「カスミの」「エリカの」「マチスの」「ナツメの」「キョウの」「カツラの」「サカキの」
    - Rocket's → 「R団の」
    - Dark → 「わるい」
    - Light → 「やさしい」
    - Shining → 「ひかる」
    - アンノーンは「アンノーンA」の形
  - 組み立てた名前は、別系統の日本版カードデータ（Scrydex 由来）と全件照合済みです（[出典と確認状況](../sources.md#カード名の照合結果)）。
- **トレーナー・エネルギーのカード名**: 手作業で対応表（`data/curation/trainers.json`）を作り、確度（確実／有力／未確認）を記録しています。
  - 名前の後ろに **※** があるものは「未確認」です（現在は該当なし）。
  - 旧裏期の基本エネルギーは「草エネルギー」のように表記しています。「基本草エネルギー」という名前になったのは LEGEND 期からです（ポケモンWiki による）。

## 日本語テキストについて

カード名は全 780 枚について日本語・英語とも収録しています。ワザ名・特殊能力（ポケモンパワー）名・効果文の日本語版は、弾によって出典が違います。

| 弾 | 日本語テキスト | 出典 |
|---|---|---|
| 第1弾〜第4弾、neo 第1弾・第2弾 | 収録（410 枚） | [なぞのばしょ](https://nazonobasho.com/) の各カードページ（自動取得） |
| 第5弾 リーダーズスタジアム、第6弾 闇からの挑戦、neo 第3弾 めざめる伝説、neo 第4弾 闇、そして光へ... | 収録（364 枚） | [ポケモンWiki](https://wiki.pokemonwiki.com/) の各カードページ（ブラウザで保存したもの。`data/raw/`） |

- 英語版の名前と文面は、全カード収録しています。
- ワザ・特殊能力・トレーナーは、全カードに日本語の名前と効果文があります。
- 基本エネルギー（第1弾の 6 枚）には効果文がないので、出典もありません。
- 未収録: 無色2個エネルギーの効果文と、アンノーン 3 枚（M・U・A）のルール文（なぞのばしょのページに記載がない）。`ja` は `null` です。neo 第1〜2弾のベイビィ 6 枚のルール文は、なぞのばしょのページの「ルール」の欄を取り込みが残していなかったもので、2026-10-27 にカードの画像で確かめて訂正の記録で入れました（[ベイビィの準備](../baby-preparation-engine-v0.113.md)）。
- アンノーンI・D・F（neo 第2弾）のルール文は、なぞのばしょのページに記載がなかったが、2026-10-24 にカードの画像（pcg-search.com・なぞのばしょ）で「「アンノーン」はデッキに4枚までしか入れることができません。」を確かめ、訂正の記録（`data/curation/card_corrections.json` の `FIX-neo2-023/025/026-RULES-TEXT-JA`）で入れました（[アンノーンの調査](../unown-research-v0.97.md)）。ほかの文字のアンノーンの文面を写したものではありません。
- 未収録のカードに英語版から訳した文は入れていません。訳文では日英の文面の違いを確かめられないためです。
- 日本のみのカード 2 枚（イマクニ？のドードー、_____のラッキー）は英語版がないので、ワザ・特殊能力・HP・弱点などもポケモンWiki の記載から作っています（英語の欄は `null`）。

### 取り込んだテキストの扱い

- 各カードの出典ページは、`data/cards.json` の `ja_text_source` と、各弾のページの「日本語テキストの出典」にあります。
  - ポケモンWiki の分は、`data/raw/` に各ページの版番号（`source_revision`）と固定リンク（`source_permalink`）も残しています。
- どちらのサイトの記載もそのまま使っています。転記には誤記があります。
  - 英語版データと数値（HP・コスト・ダメージ・にげる・タイプ・弱点・抵抗力）を突き合わせ、食い違いは全件確認しました（`data/curation/*_review.json`）。タイプ・弱点・抵抗力は 2026年10月から比べています。
    - なぞのばしょ: 24 件のうち 23 件はサイトの誤記。14 件は Scrydex 由来の日本版データが、9 件は pcg-search のカードの画像が英語版と一致しました。残りの 1 件は英語版データの誤り。
    - ポケモンWiki: 3 件とも転記の誤記・表記の揺れでした。
  - 数値は英語版データの値を使っているので、サイトの数値の誤記はカードリストには入っていません。
  - 効果文の誤字は確認しきれていません。
- ポケモンWiki のトレーナーのページには、再録された版ごとの説明文が並んでいることがあります。
  - 旧裏の版（「PMCG」「neo」「リーダーズスタジアム」などの注記がある欄、なければ注記のない欄）を選んでいます。
  - タケシは、拡張パックの版（リーダーズスタジアム）と構築済みデッキの版（ニビシティジム タケシ）の 2 つがあり、拡張パックの版を使っています。デッキの版は「(ダメージカウンターののっていないポケモンには、何もおこらない)」が加わっているだけで、意味は同じです。
  - 全 73 枚について、英語版の文面と意味が対応していることを確認しました。意味が違うものは [カードの日英の違い](card-differences.md) に載せています。
  - ポケモンWiki の「種類」欄（グッズ・サポーターなど）は現在の分類なので使っていません。
- 取り込みの手順は [scripts/README.md](../../scripts/README.md) を参照。

### 日本語テキストを手で入れるには

- `data/curation/ja_text.json` にカード id ごとに書き、`scripts/build_cardlist.py` を実行すると反映されます（なぞのばしょ・ポケモンWiki の取り込みより優先されます）。
  - 書式はファイル内の `_example` を参照してください。
- 現物、公式資料、または出典のはっきりした転載から一字一句写したものだけを入れ、`source` に出典を書いてください。

## 出典データと限界

- 日本版の収録構成とレアリティ: [TCGdex cards-database](https://github.com/tcgdex/cards-database)（MIT ライセンス）の `data-asia/PMCG`・`data-asia/neo`。
  - このデータの日本語テキスト（ワザ名・効果文・一部のカード名）は英語からの機械翻訳と見られ、公式の日本語テキストではありません。このリストでは使っていません。
  - 出典データでは、「闇からの挑戦」に「イマクニ？のドードー」「_____のラッキー」の 2 枚が入っています。どちらも通常のレアリティ構成から外れるカード（ポケモンWiki の記載では「☆」「◇」）で、拡張パックへの封入のされ方は未確認です。
- 英語版のカード情報: [PokemonTCG/pokemon-tcg-data](https://github.com/PokemonTCG/pokemon-tcg-data)。データの誤り・欠落（Neo Genesis のレディバのダメージ欄、Neo Discovery のブラッキーのだましうちの効果文、Legendary Collection のサンダース・ベトベター・ゴースのワザ名・コスト）は `data/curation/en_fixes.json` で補正しています。英語版データのレベル（LV.）には誤りが多いため使っていません。
- 日本版のテキスト・レベル・収録商品・印刷上の備考: なぞのばしょとポケモンWiki（上記）。
- 日本語カード名・レアリティ・数値の照合: Scrydex 由来の日本版データ（第三者のリポジトリにある写し）。照合に使っただけで、データ自体は収録していません。
- 日本語のポケモン名: [PokeAPI](https://github.com/PokeAPI/pokeapi) の `pokemon_species_names.csv`。
- 日本版と英語版の対応付けは、図鑑番号・HP・ワザのエネルギーコストとダメージ・名前の接頭辞（ジムリーダー名など）を突き合わせて自動で行い、自動では決まらないものを `data/curation/pokemon_overrides.json` で補正しています。
- ワザ・ポケモンパワー・弱点・抵抗力・にげるコスト・効果文（いずれも英語版の値）は `data/cards.json` に構造化して入っています。表形式の写しは `data/cards.csv`（カード 1 枚 1 行）、`data/attacks.csv`（ワザ 1 つ 1 行）、`data/powers.csv`（ポケモンパワー 1 つ 1 行）です。

生成手順は [scripts/README.md](../../scripts/README.md) を参照。
