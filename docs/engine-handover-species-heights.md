# エンジンへの引き継ぎ: 公式図鑑の種族の身長（2026-10-31）

kyuura-engine で「カツラのクイズ その1」（GD5-016 ほか）を扱うときの、参照データ [`data/species_heights.json`](../data/species_heights.json) の引き継ぎです。収集の記録は [species-heights.md](species-heights.md) です。

## 1. いまの状態

- No.001〜251 の **251 件すべてを取得済み**（`status: "confirmed"`）。出典は公式のポケモンずかん（`zukan.pokemon.co.jp`）の詳細ページ（通常の姿）、取得日は 2026-10-31。ほかの公式の資料とは比べていません。
- サイトの利用条件のページ（`www.pokemon.co.jp`）は読めていません（[species-heights.md](species-heights.md) 1 章）。
- 名前は公式の表記のままです（No.233 は全角数字の「ポリゴン２」。カード名は「ポリゴン2」）。カードとは名前ではなく図鑑番号で結んでください。

## 2. 使いかた

- カードの種族は `data/cards.json` の `pokemon.dex`（全国図鑑番号）だけで引きます（`scripts/species_heights.py` の `species_for_card`）。`dex` のないカード（2026-10-31 に 227 枚）は結べません。名前の文字列（所有者名つきカードを含む）から推測しないでください。
- 使ってよいのは `status` が `confirmed` の項目の `height.cm`（整数 cm）だけです。`unverified`・`conflict`・`needs_review` は値を持ちません（`conflict` は `observations` に出典ごとの値が残る）。
- 照合のときは、写しを作った kyuura のコミットと `data/species_heights.json` の `sources.*.access_log`・観測の `retrieved_on`・`response_sha256` を記録してください。

## 3. エンジンの仕様として別に決めること（kyuura は決めていない）

- **正解の基準**: 公式図鑑の種族の値（今の公式ずかん）を正解にするか。カードの時期（1996〜2001年）の図鑑や、カードに印刷された身長と同じかは確かめていません。このデータは「旧裏カードの印刷された身長」ではありません。
- **答えの比べ方**: 答えの単位・桁（m と cm、小数の書き方）と、どこまで一致すれば「正解」か。カードの文面（「その身長を答えてもらう」）はこれを書いていません。
- **姿**: 通常の姿だけを集めています。アンノーンの文字の違いなど、カードの姿と図鑑の姿が 1 対 1 でない場合の扱い。
- **値がないとき**: 図鑑番号のないカード（227 枚）・今後の未確認の種族を置いたときの扱い（成功を仮定せずに止めるか、未対応のままにするか）。

これらはカードの文面と公式の資料で決まっていない事項で、kyuura の裁定・未解決の論点（`data/sidecar/rulings.json`）としてはまだ立てていません。
