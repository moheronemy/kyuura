- 4 枚とも、タイプと必要なエネルギーの記号が違うのは印刷のとおりで、データの入れ違いではない。固定した入力・転記・対応付け・生成のどこにも誤りは見つからなかった。訂正・訂正の候補は作っていない（before と after が同じ訂正を作らない）。
- サイトの転記（画像の読み取りと分けた。照合の数に入れない）: pcg-search のページの記号の画像（`en003` 水・`en006` 闘・`en000` 無色。記号の画像を取得して確かめた）と、なぞのばしょのページの文字（「タイプ 水」「ちからをあわせる 闘無」など）。どちらも画像と同じ。
- 特定に使っただけで、確かめた欄にしていないもの: 弱点・抵抗力・HP・にげる・進化元・LV・図鑑番号。新しい疑問は見つからなかった。なぞのばしょのオムナイトの「進化条件」は「なにかのか化石から進化」（サイトの誤記。画像は「なにかの化石から進化」。kyuura の値は「なにかの化石」で、対象外の欄）。
- 拡張パックの記録には `field_sources` がない（拡張パック以外の商品の記録だけの欄）ので、確認は照合の記録 `IMG-` にだけ残した。
