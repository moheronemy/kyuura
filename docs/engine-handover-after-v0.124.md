## 4. コインで決まる枚数の不足（UQ-STATED-COUNT-SHORT）

**未解決のまま**です（4 枚・5 つの id を事例として加えた。問い・分類・過去の監査は変えていない）。当時の日本語の資料で、足りないときを書いたものは見つかっていません（探した範囲は論点の記録。資料が見つからないことは、当時の裁定がないことではない）。

| 処理 | 決まったこと（CONFIRMED） | 未解決 |
|---|---|---|
| マウンテンクラッシュ | 30 ダメージが先。そのあと「おもて」の数ぶん相手の山札の上からトラッシュ。山札がなくなっても、その時点では負けない（負けは自分の番の最初に引けないとき） | 山札が「おもて」より少ない（1 枚以上）とき、あるだけトラッシュするか・しないか |
| 怪電波マシーン | 相手の対戦ポケモンからはがして**相手の手札**にもどす。使ったら番が終わる | エネルギーカードが「おもて」より少ないとき・0 枚のとき。番の終わりと不足の答えの関係 |
| ドライアップ | 相手の場から 1 匹を**選んでから**投げ、そのポケモンの「水」エネルギーカードを**トラッシュ**（p.82 の最新の説明・解説） | 水が「おもて」より少ない・0 枚（水以外だけ）のとき |

## 6. エンジンで見直すこと（実装上の問題。kyuura の裁定ではない）

- **結果のまとめ方**: 上限なしのコインで、「おもて」の数が有限の枚数を超える結果がある。引く処理の `min(H, D)` のまとめ方（`draw_classes`。0〜D と D 以上を 1 つの組）は p.312 の「引けるだけ」による。トラッシュ・手札にもどす処理に根拠なく流用しないこと。H = D と H = D + 1 を同じ組にまとめると、不足の場面が隠れる。
- **実際のコイン**: 資源の数でコインを打ち切らないこと（CR-UNTIL-TAILS-NOT-CAPPED）。先読みで代表の値を使っても、実際のコイン・ログ・乱数は「うら」が出るまで。
- **宣言の前の先読み**: 不足する結果を宣言の前の先読みで拒否するだけでは、上限なしのコインでは、ふつうの有効な対象（山札・エネルギーカードが有限）でも不足の結果がいつもあるので、宣言がいつも止まりうる。これは実装の問題で、資料の裁定ではない（不足の答えが決まるまでは、コインのあとで不足したときに止める形などを検討する）。
- **怪電波マシーンの番の終わり**: トレーナーの途中で止めるなら、番の終わりの前で止まり、状態・乱数・ログが変わらないことを確かめる。
- **ドライアップの選択**: 選ぶのはコインの前。選べるものを「水エネルギーカードがついているポケモン」に限るのは文面にない（限る・限らないは不足の問いの一部）。
- **［てだすけ］はベンチだけ**: v0.124 はコピーで能力を持てるが、宣言する能力で写すことを確かめた型は 4 つだけ（`COPY_VERIFIED_DECLARED`）。両方のメタモンが変身を保つ場所（［へんしん］はバトル場、［すごいへんしん］はバトル場）との関係で、所持・場所・使用・使用回数の問題を分ける。コピーして［てだすけ］を使える経路がなければ、総当たりのテストを要求しない。
- **［すごいへんしん］と炎**: Super（すごいへんしん）で色を払えることと、「「炎」エネルギーカード」として数えることは別（後者は SV5 の問い）。はかいのほのおの N をこの支払いから数えない。
- **回復と姿の変化**: ［てだすけ］で特殊状態を回復しても［すごいへんしん］の姿はもどらない（もどるのは特殊状態のとき。CR-SUPER-TRANSFORM-REVERT-CONDITIONS）。回復でガス・姿・最大 HP が変わる組み合わせがあれば、`frozen_forms` と能力の終了の処理に合わせる。これを kyuura の新しい公式の裁定として書いていない。
- **ふくらむの段階**: p.321 の 8（SUPPORTED）。持続する効果の型を加えるときは、自分自身に与える効果の不変条件（発生源）・期限（次の相手の番の終わり）・消える契機を見直す。
