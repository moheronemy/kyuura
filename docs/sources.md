## 調べ方について

- ルール関係の文書は、ウェブ検索の結果（検索エンジンが返す要約と抜粋）をもとに書いています。
- 作成環境のネットワーク制限のため、下記のページの多くは直接開いて読めていません。内容は検索結果の要約で確かめたものです。
  - 例外: Bulbapedia の X10、X11、X30、X31、X37、X38、X41〜X56 は、2026年10月に MediaWiki の API でページの原文（ウィキテキスト）を取得して確かめました。
  - なぞのばしょ（J22、J23、J25〜J28、N1）と pcg-search（N3。カードの画像を含む）も、ページを直接取得して読みました。
  - 2026年10月の追加の検証で、Internet Archive（web.archive.org）と note.com を開けるようになりました。
    - 公式サイトの Q&A [P10] は、Internet Archive に保存された写し（2002-06-10・2005-10-18・2007-02-09）で原文を読みました。
    - 旧裏 wiki（wikiwiki.jp）は、サイト側の Cloudflare の確認画面（HTTP 403）で直接は開けませんでした（回避はしていません）。Internet Archive に保存された写しで、J1（2026-03-20 の保存）、J6（2026-01-28 の保存）、J36（2026-02-06 の保存）の本文を読みました。
    - note の J30、J31、J32 は記事を直接取得して読みました。J32 の記事の中の画像（assets.st-note.com。新ガルーラルールの説明の誌面の写真）は、その後に許可され、文面を確認しました。記事の説明は『トレーナーズ』Vol.14 p.21 としていますが、スキャン [J37] で照合すると Vol.15 p.21 のページでした。
    - 公式サイトのページ（P15〜P23）は、Internet Archive に保存された写しで原文を読みました。画像で書かれた部分は、保存された写しをブラウザで表示して確かめました。
    - ポケブーン（J33・J34）は直接取得して読みました。駿河屋（J35）は作成環境のネットワーク制限で開けませんでした（回避はしていません）。
    - その後、elitefourum.com と drive.google.com が許可され、Elite Fourum のスレッドで公開された Google Drive の PDF [J37] で、『トレーナーズ』Vol.1〜21（全号）、『ポケモンカード・ファンクラブ』Vol.1〜5（全号）、ガイドブック [P29]、『めざせ! ポケモンカードマスター』[P34] の誌面を確認しました。
      - Drive の PDF は、drive.google.com のビューアーがページごとに返す画像で読みました。ファイルの直接のダウンロード（drive.usercontent.google.com）とビューアーのスクリプト（www.gstatic.com）は、作成環境のネットワーク制限で開けませんでした（回避はしていません）。
      - スレッドの最初の投稿の OneDrive（1drv.ms）のリンクも開けませんでした。同じ Drive のフォルダの「Silver Bible」（『ポケモンカード オフィシャルブック2000』とされる PDF）は、ビューアーがページの画像を返さず、読めませんでした。「Rulebooks」のフォルダには韓国語版のルールブックしかなく、使っていません。
      - スキャンは個人が自分の所有する冊子を取り込んで公開したもので、号数・ページは誌面の表示（表紙・ノンブル・奥付）で確かめました。
    - 2003年の公式サイトのページ（P28）も、Internet Archive に保存された写しで原文を読みました。
  - ポケモンWiki、Wikipedia、ポケブーン、上記以外の旧裏 wiki のページと note などは、作成環境のネットワーク制限で開けていません。これらは検索結果の要約だけで確かめています（回避はしていません）。
  - 引用の文言が原文と一字一句同じとは限りません。
  - 要約の取り違えが含まれている可能性もあります。
- 公開・引用の前に、各ページを開いて確認してください。特に、旧裏 wiki「当時のルール」[J1] と、WotC の Advanced Rulebook [E4][E5] を優先してください。

### カード名の照合結果

- **ポケモンのカード名**: 図鑑番号から組み立てた名前を、Scrydex 由来のデータの日本語名と全件照合しました。両データの不一致は 2 種類だけでした。
  - 「R団の」の表記: Scrydex 由来の名前に合わせました。
  - 数字の全角・半角
- **ポケモンのカード名となぞのばしょ**: なぞのばしょのカード名とも照合し、食い違いはサイトの誤記 3 件だけでした（トランセルのページが「キャタピー」、「ダクトリオ」、アンノーンD のページが「アンノーン[I]」）。
- **カード名とポケモンWiki**: 食い違いは 2 件で、どちらもサイトの転記の誤りと判定しました（「カツラのウィンディ」、空欄の長さが違う「_のラッキー」）。
- **トレーナー名の修正**: ポケモンWiki の表記に合わせて、闇からの挑戦の「キョウ秘伝 変わり身の術」を「キョウ秘伝,変わり身の術」にしました。
- **トレーナー・エネルギーのカード名**: 確度を `data/curation/trainers.json` の `confidence` に記録し、なぞのばしょのカード名と一致したものは確度を一段上げています（`data/cards.json` の `name_ja_confidence` が最終的な確度）。
  - ポケモンWiki のカード名と一致したものも同じく一段上げています。
  - **確実**（132 枚）: 互いに独立した 2 系統以上の出典で一致。
  - **有力**（21 枚）: 出典が 1 系統、または独立かどうか分からない 2 系統で一致。
  - **未確認**: 0 枚。以前は闇からの挑戦の「ロケット団の実験」が TCGdex にしかない名前でしたが、ポケモンWiki のカード名と一致して有力になりました。
  - なぞのばしょの表記に合わせて、第1弾の 3 枚を修正しました: 元気のかけら（TCGdex は「げんきのかけら」）、ポケモン図鑑 HANDY505（同「ポケモン図鑑」）、無色2個エネルギー（同「ダブル無色エネルギー」）。
- **レアリティ**: TCGdex と Scrydex 由来のデータで、ひかるポケモン 10 枚と、デルビル（闇、そして光へ...）の表記が食い違っています。カードリストの備考に記載しています。
