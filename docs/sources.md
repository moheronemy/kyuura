# 出典と確認状況

## 調べ方について

- ルール関係の文書は、ウェブ検索の結果（検索エンジンが返す要約と抜粋）をもとに書いています。
- 作成環境のネットワーク制限のため、下記のページはどれも直接開いて読めていません。内容は検索結果の要約で確かめたものです。
  - 引用の文言が原文と一字一句同じとは限りません。
  - 要約の取り違えが含まれている可能性もあります。
- 公開・引用の前に、各ページを開いて確認してください。特に、旧裏 wiki「当時のルール」[J1] と、WotC の Advanced Rulebook [E4][E5] を優先してください。

### カード名の照合結果

- **ポケモンのカード名**: 図鑑番号から組み立てた名前を、Scrydex 由来のデータの日本語名と全件照合しました。両データの不一致は 2 種類だけでした。
  - 「R団の」の表記: Scrydex 由来の名前に合わせました。
  - 数字の全角・半角
- **トレーナー・エネルギーのカード名**: 確度を `data/curation/trainers.json` の `confidence` に記録しています。
  - **確実**: Bulbapedia・nazonobasho・旧裏 wiki などのページと、Scrydex 由来のデータが一致。neo 第1弾のトレーナーの大半。
  - **有力**: TCGdex と Scrydex 由来のデータの 2 系統が一致したもの、またはどちらか一方に加えて中古販売ページなどで表記を確認できたもの。
  - **未確認**: TCGdex にしか日本語名がないもの。カードリストでは名前の後ろに ※ を付けています。
- **レアリティ**: TCGdex と Scrydex 由来のデータで、ひかるポケモン 10 枚と、デルビル（闇、そして光へ...）の表記が食い違っています。カードリストの備考に記載しています。

## カードテキスト

- 英語版の名前と文面（ワザ・ポケモンパワー・トレーナー・特殊エネルギー）: PokemonTCG/pokemon-tcg-data（全件）。
- 日本版の名前と文面: 未収録。公式の印刷文面を写したデータが、作成環境から手に入らなかったため（[詳細](cards/README.md#日本語テキストについて)）。
  - 収録には、印刷文面を載せているサイト（例: wikiwiki.jp の旧裏 wiki、nazonobasho.com、ポケモンWiki）への接続が必要です。
