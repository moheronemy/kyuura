# エンジン開発の準備状況

旧裏期のルールを再現するゲームエンジンについて、調査データのどこを基準にするか、何が公式の文面で確かめられていて何が未確認かを整理したページです。

**現在の状況（2026-10-13）**: エンジンは別のリポジトリ [kyuura-engine](https://github.com/moheronemy/kyuura-engine) で開発されていて、v0.13（ブランチ `claude/v0.13-shell-attack`、コミット `8facf3a`）まで進んでいます。エンジンは kyuura のコミット `ecb2d69`（`ecb2d694e6280ec5dc9ddd2a8f709cea16a6b691`）の `data/cards.json` を写して使い、基準のルールはこのページで選んだ公式ルール 2000.02.14版です。エンジンが原典と照合した結果のうち、v0.13 のわるいカメールの「こうらがえし」の最新の説明・裁定・未解決の論点は kyuura に取り込みました（[カードの裁定と公式の最新の説明](rules/card-rulings.md)、データは `data/sidecar/`）。エンジンの実装状況（対応しているカード・止めている裁定）はエンジンのリポジトリの `docs/implementation-status.md` にあり、kyuura では追っていません。エンジンの実装は公式の裁定ではないので、kyuura には公式の資料で確かめた内容だけを記録します。

1〜8 章は、エンジンを作り始める前（2026-10-12）の計画と判断の記録です。5 章の「最初の小さな対戦の候補カード」などは当時の計画で、今のエンジンの実装範囲ではありません。

出典の記号は [出典と確認状況](sources.md)、確度の表記は [ルール資料の README](rules/README.md) と同じです。

## 2. 最初に再現するルールの選び方

候補は次の 3 つです。

| 候補 | 本文を読めたか | カードの文面の基準 | 主な問題 |
|---|---|---|---|
| ルールブック第4版の冊子（1998年）[P44] | 全ページを読んだ | 冊子にカードの文面の一覧はない。プラスパワーとディフェンダーは第1弾の文面で引く | 発行日・刷の表示がなく、1998年1月1日の発表時の文面と同じか未確認。こんらんでワザが失敗したときの「こんらんしたワザ」は、ワザごとにダメージと効果を自分に向け直す処理で、カードごとの解釈が多い |
| 第5版（1999年）の再構成 | 文書そのものは読めていない。『トレーナーズ』Vol.1 p.30 の変更点 4 つだけ [P32] | 1999年の時点の文面の一覧は見つかっていない | 変更点以外の項目は、第4版から変わらなかったと仮定するしかない。その仮定を確かめる資料がない |
| 公式ルール 2000.02.14版（2000年）[P43] | 全文を読んだ（pp.306〜326） | 同じ本が、第1弾からネオまでのカードを「最新の説明」で載せ、「わからない内容があれば、この記述にしたがってください」とする（p.6） | ネオの要素（ベイビィポケモン、悪・鋼エネルギー、ポケモンのどうぐ、スタジアム）を含む。カードの範囲を絞れば外せる |

2000.02.14版を最初の対象にします。理由は次のとおりです。

- ルールの全文と、カードごとの文面の基準が、同じ本にそろっています。ルールとカードの文面の時期が食い違いません。
- 対戦準備・番の流れ・ワザの手順・ダメージ計算・特殊状態・ポケモンチェック・勝敗とサドン・デスまで、手順として書かれています。
- 第5版の変更点 4 つ（引き直しの補償、対戦準備のベンチ 5 匹、先攻の最初のドロー、こんらんの 20 ダメージ）は、どれも 2000.02.14版と同じ内容です [P32][P43]。第5版は「2000.02.14版からネオの要素を除いたもの」に近いとみられますが、ほかの項目が同じかは確認できていません（推定）。

第4版の冊子は、2つ目のルールの組として後で加えます。第5版は、2000.02.14版との違いが確かめられた項目だけを切り替える形にし、確かめられない項目は「未確認」と明示します。

## 4. 実装の前に解釈や判断が要る点

### 解釈が必要な処理

公式の文面はあるが、手順として一つに決めるには読み方を決める必要があるものです。決めた読み方は、根拠のページとともにテストに書きます。

- **切り直しの回数が両方で違うとき**: 文面は「両方のプレイヤーとも」たねポケモンがなかったら、どちらも引かないとします。片方が 1 回、もう片方が 2 回切り直したときの枚数は書かれていません。
- **ポケモンチェックの「指示されたこと」**: カードの説明で「ポケモンチェックのとき」と指示された処理を、どく・ねむり・マヒより先に行います。指示された処理が複数あるときの順番は、カードの範囲を広げるときに決めます。
- **ダメージ計算で同じ段階に複数の効果があるとき**: 文面は、計算の順番をワザを使うプレイヤーが決めるとします（OCR で位置を確かめた。画像で照合する）。最初の範囲では起きません。
- **同時のきぜつ**: 文面は、1 つのワザなどで複数のポケモンがきぜつしたら「同時」とし、両方の対戦ポケモンがきぜつしたら、今が自分の番でないプレイヤーから先に新しい対戦ポケモンを出すとします（OCR で位置を確かめた。画像で照合する）。第4版の冊子も同じ順です [P44]。

### 裁定として決める必要があるもの

- **カードの「相手」「自分」**: 2000年の公式ルールは、カードの説明の太字の「相手」「自分」を、相手の対戦ポケモン・自分の対戦ポケモンの意味とします。第1弾の転記では太字が区別されていないので、カードごとに対象を決めて記録します。
- **先攻の最初の番のワザ・トレーナー**: 制限しません。旧裏期に制限がなかったことは二次資料と当時の誌面で確かめています（[first_turn_actions](rules/differences.md#first_turn_actions)）。第4版の冊子にも制限の記述はありません [P44]。2000年の公式ルールも、OCR で探した範囲では「最初の番」の規定は進化の項だけです（画像で照合する）。
- **ワザの「ダメージ」と「効果」**: ワザの説明の要素は書かれた順に処理し、ワザを受けたポケモンが「ダメージを受けない」状態ならダメージだけ、「ワザを受けない」状態ならダメージと効果を無効にします（『トレーナーズ』Vol.4 [P37]。第4版の冊子 pp.41〜42 も同じ区別 [P44]）。『トレーナーズ』Vol.5 は、ダメージを先に、そのほかの効果を後に処理するとします（`NEO-2000-PLAYRULE`）。ダメージと効果の区切りは、カードごとに記録します。
- **特殊状態と特殊能力**: 特殊状態で特殊能力が使えなくなる一般規定は、2000年の公式ルールにも第4版の冊子にもなく、カードの文面によります（リザードンは「最新の説明」で「ねむり・マヒ・こんらん」状態のとき使えない。`TXT-CHARIZARD`）。特殊能力を持つカードは最初の範囲に入れません。

### 時期で変わるルール

エンジンは、ルールの組（どの時期のルールで対戦するか）を切り替えられる形にします。本文を読めた 2 つの公式ルールで違う項目は、[第4版の冊子と公式ルール 2000.02.14版の違い](rules/japanese.md#第4版の冊子と公式ルール-20000214版の違い) にまとめています。

- 引き直しの補償と負けの規定、対戦準備のベンチの数、先攻の最初のドロー、こんらんでワザが失敗したときの処理、ダメージ計算の段階、ポケモンチェックの「指示されたこと」、スタジアムの有無。
- 公式大会のルール（サイド 4 枚、大会専用の先攻のドローなど）は、基本ルールとは別の「レギュレーション」として扱います（[tournaments](rules/differences.md#tournaments)）。
- カードの文面の時期: プラスパワーは 1998年の第1弾の文面と 2000年の「最新の説明」で違います（`ERR-PLUSPOWER`）。エネルギー回収は 1998年6月の会報から基本エネルギーだけ（`ERR-ENERGY-RETRIEVAL`）。タケシのキュウコンは 2000年5月の変更があり、2000年2月の時点ではまだ制限がありません（`ERR-BROCK-NINETALES`）。

### カード効果を実装する前に確認すること

- 各カードの日本語の文面は、なぞのばしょ・ポケモンWiki の転記です（`ja_text_source`）。『オフィシャルブック2000』で読んだカードのページは、エラッタ・日英の違いにかかわるものだけです。対象にするカードは、その本のカードのページで「最新の説明」を読み、転記と照合してから実装します。
- HP・弱点・抵抗力・にげる・ワザのエネルギーとダメージは英語版データから入れ、日本語の転記と比べてあります（[調査の状況](research-status.md#カード)）。対象のカードは、同じ本のカードのページの数値とも照合します。
- 炎エネルギーをトラッシュするワザは、2000年に説明文の書き方が変わっています（`RUL-ENERGY-DISCARD-ATTACKS`）。ヒトカゲの「ひのこ」などは、この記録を見てから実装します。

## 6. 未確認のまま残すもの

最初の範囲にかかわらないので、実装を始める妨げにはしません。

| 未確認の点 | 最初の範囲への影響 |
|---|---|
| 第1〜3版・第5版のルール文書の本文 | なし（2000.02.14版を使う） |
| 第4版の冊子と 1998年1月1日の発表時の文面が同じか、刷の時期 | なし（第4版のルールの組を加えるときに注記する） |
| 第4版で、こんらんで自分にかかったダメージに弱点を計算するか（冊子に書かれていない。会報 Vol.4 の Q&A は計算するとする [P1]） | なし |
| 第4版以外の版での最初の番の進化の制限 | なし |
| 1998年のスタジアムのルール（第4版の冊子に記述がない） | なし（スタジアムは最初の範囲外） |
| プラスパワー・エネルギー回収などのエラッタを、古いカードに使い始めた日 | なし（2000年2月の時点の文面を使う） |
| ポケモンのどうぐの規定の文言、くろこげマーカー・悪エネルギーのポケモンチェックでの順番 | なし（ネオの要素は範囲外） |
| 無色2個エネルギーの日本語の効果文、ベイビィ・アンノーンのルール文 | なし |
| 英語版（WotC）のルールの原文 | なし（日本版を再現する） |

## 7. 実装を始めるときに確認すること

1. 実装する手順ごとに、『オフィシャルブック2000』pp.306〜326 の該当ページを画像で読み直し、ページ番号をテストに書きます。この調査では、OCR は語句の位置を探すのに使っただけで、[4章](#4-実装の前に解釈や判断が要る点) の「OCR で位置を確かめた」項目は画像で照合していません。
2. 対象のカードごとに、同じ本のカードのページの「最新の説明」と数値を読み、`data/cards.json` の転記と照合します。違いがあれば調査データに記録してから実装します。
3. ルールの組の項目は、`data/rule_differences.json` の項目 id（`mulligan`、`setup_bench` など）に合わせます。各項目の値に、根拠の記録（`NEO-2000-OFFICIAL-RULES` など）を対応させます。
4. 根拠がない項目は、黙って既定値を入れず、「未確認」として扱います（ルールの組を切り替えたときに、未確認の項目が分かるようにする）。

## 8. 新しい資料が見つかったとき

- 調査データ（`data/rule_history.json`・`data/rule_differences.json`・`data/cards.json`）を先に直し、生成スクリプトの検査を通します。
- 基準にするルールの版を上げ、変わった項目に対応するテストを直します。基準にした調査データのコミットを記録しておけば、どの資料の状態に基づくテストかを追えます。
- 第4版・第5版のルールの組は、版の文書や同じ時期の公式資料で確かめられた項目から加えます。
