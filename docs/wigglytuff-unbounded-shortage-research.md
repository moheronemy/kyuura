## 3. 優先A: プクリン（ES1-027）

### 3.1 p.226 の欄

- PDF 228 のページの下の番号は「226」（PDF n = p.(n−2) の対応どおり）。3 つの欄のうち 3 つ目が「プリンから進化 プクリン LV.40／HP90 ●拡張シート第1弾青版」。図版は 1進化・無色・［特殊能力］てだすけ・ふくらむ（無色 4 個・20）・弱点 闘・抵抗力 超 -30・にげる 3 で、カードの画像 IMG-ES1-027 と同じ印刷。1 つ目の欄（エリカのプリン PMCG5-058）・2 つ目の欄（プクリン LV.36／HP80 ●ポケモンジャングル PMCG2-045）とは別。
- 最新の説明（画像の文。既存の転記と照らしただけで、引用の根拠は画像）:
  - ［てだすけ］: 「この力は、自分の番ごとに1回、このカードがベンチにいるとき使える。コインを投げて「おもて」なら、自分の対戦ポケモンの「どく・ねむり・マヒ・こんらん」状態のうちの1つを回復させる。」（転記と同じ）。
  - ふくらむ: 「次の相手の番、このカードが受けるダメージは「-10」される。（ダメージ以外の効果はそのまま）」（「され／る。」で行が分かれる。括弧は全角。転記は半角の「(…)」で、ほかは同じ）。
- 解説: ［てだすけ］は「ベンチにいるときしか使えない」、「コイントスで表を出さなければ効果はない」。ふくらむは「受けるダメージを10減らせる」。

### 3.2 印刷の 1 字

- 書籍の図版のふくらむも「このカ ドが次の相手の■に受けるダメ／ージは「10」される。」と見え、■ は字の形が読めない（スキャンの画像の解像度）。「-」も見分けられない。カードの画像（IMG-ES1-027）と同じ位置の字で、図版でも決まらない。
- **最新の説明を採用しても、印刷の 1 字が読めたことにはしない。** kyuura の文面（転記「次の相手に受ける」）は変えず、訂正の候補（`held_illegible_print`）のまま。候補に `later_notes` を追記した（過去の文は変えていない）。CC-ES1-027-P226 は、この欠けを data_error（candidate）として書いた（新しい訂正ではない）。
- 実装が使う文面: ふくらむは最新の説明（LD-ES1-027-ATK0。p.6 で、わからない内容はこれにしたがう）。印刷の字を「番」と補った文面を「印刷」として使わない。

| CR-HELPING-HAND-USE | CONFIRMED | ベンチにいるとき、自分の番ごとに 1 回。「おもて」で自分の対戦ポケモンの 4 つの状態のうち **1 つだけ**を回復（全部ではない）。「うら」なら何もしない |

### 3.4 残る問い

- UQ-HELPING-HAND-CHOICE（新）: どくと、ねむり・マヒ・こんらんの 2 つがあるとき、回復する 1 つをだれが、いつ選ぶか（説明・解説に書かれていない）。

### 4.4 結論が要る場面と、残る問い

UQ-STATED-COUNT-SHORT は**未解決のまま**です。コインで決まる数も「書かれた数より少ないとき、あるだけ処理するか・その要素を処理しないか・使えないか」という同じ問いとみて、5 つの事例を加えました（問い・分類・過去の監査は変えていない）。ほかのカード全体の枚数不足は、この調査で解決済みにしていません。

| 処理 | 場面 | 今の答え |
|---|---|---|
| マウンテンクラッシュ | 山札 2 枚・「おもて」3 以上 | 30 ダメージは残る（先に処理。CONFIRMED）。トラッシュを 2 枚するか・しないかは未解決 |
| | 山札 0 枚 | 30 ダメージは残る。トラッシュは 0 枚（何もない）。p.309 の「対象がなくなっている」はポケモンなどの文で、山札 0 枚にそのまま当てはまるとはしない（事例の注記） |
| | 「おもて」0（H = 0） | トラッシュするカードはない（不足ではない） |
| 怪電波マシーン | エネルギーカード 2 枚・「おもて」3 以上 | もどせるだけもどす／もどす処理をしない、のどちらかは未解決。足りるかはコインのあとで分かるので、宣言の前に「使えない」とはできない（事例の注記）。番の終わりは「使ったら」で、もどす処理の答えと別と読めるが決めていない |
| | エネルギーカード 0 枚 | 使えるか（使えば番が終わる）は UQ-CARD-USE-WITHOUT-TARGET の事例 |
| ドライアップ | 水 2 枚・「おもて」3 以上 | 未解決（あるだけか、処理しないか） |
| | 水 0 枚・水以外だけ | 印刷・最新の説明は選ぶポケモンを限らない。水以外はトラッシュしない。0 枚のポケモンを選べるか・選んだときの処理は事例の注記に残した |

- コインは、カードの数に関わらず「うら」が出るまで投げる（CR-UNTIL-TAILS-NOT-CAPPED）。有限の資源に合わせてコインを打ち切る処理は、実装の都合で採用しない。

### 4.5 はかいのほのお

- 新しい論点 UQ-DESTRUCTIVE-FIRE-FAILURE（未解決）:
  - N > 0・H = 0（すべて「うら」）: 0 枚をトラッシュした（できた）ことになるか、「トラッシュできない」に当たって失敗するか。50 ダメージを与えるか。たつまきなどの「すべて「うら」なら失敗」とは文面が違い、同じとは決めない。
  - N = 0: コインを投げず H = 0。炎の記号を炎エネルギーカードなしで払う場面（変身して基本エネルギーを使う［すごいへんしん］など）がある。普通のコストに炎があることで「到達しない」とはしない。一方、色を払えることを「「炎」エネルギーカード」として数える根拠にもしない（UQ-SPECIAL-ENERGY-AS-TYPED-ENERGY・UQ-SUPER-TRANSFORM-ENERGY-COLORS）。
  - 順番: p.309 はダメージの処理を先にするが、「失敗する」と書いた条件をいつ判定し、失敗したとき与えた 50 ダメージをどうするかは書かれていない（直接の裁定はない。推論もしていない）。
  - 相手が「ダメージを受けない」状態など、相手への要素が無効なとき（不足とは別の場面）。UQ-COIN-IN-NULLIFIED-ELEMENT と関係。
  - p.66 のわるいリザードンの解説（れんぞくファイヤーボール。「裏が出ても、エネルギーをトラッシュすることもなく」）は、ダメージが「おもて」の数で決まるワザの解説で、50 ダメージのはかいのほのおの答えにはしなかった。
- 相手側の不足（自分の炎は H 枚トラッシュできたが、相手のエネルギーカードが H より少ない）は UQ-STATED-COUNT-SHORT の事例。
- 特殊エネルギーの数え方は UQ-SPECIAL-ENERGY-AS-TYPED-ENERGY の事例（基本の炎だけの H = 0・相手側の不足と一括で決めない）。
