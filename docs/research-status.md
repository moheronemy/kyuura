# 調査の状況

この資料集で、どの分野をどこまで確かめられたかをまとめたページです。個々の記述の根拠は、各ページの出典の記号と確度（**確実**／**有力**／**未確認**）で示しています。このページはその集計と、まだ足りないものの一覧です。

- 資料があること、資料を読めたこと、その資料が特定の記述を裏付けることは、別のこととして扱っています。資料ごとの読めた範囲は [出典と確認状況](sources.md#調べ方について)、当時の印刷物のページごとの記録は [印刷物の照合記録](printed-sources.md) にあります。
- 数は `python3 scripts/research_stats.py` の出力を写したものです（[数えた時点](#数えた時点)）。データに項目として記録されていることだけを数えています。分母がはっきりしないものには割合を付けていません。
- 検証スクリプトが正常に終わることは、データの形と参照の整合を示すだけです。歴史的な内容がすべて正しいことを示すものではありません。

## 3. 主な未解決の問題

1. **ルール文書の本文**: 第1〜3版・第5版のルールブック・遊びかた説明書は読めていない。第4版は冊子を読んだが、刷の時期と 1998年1月1日の発表時の文面との関係、第3版から変わった点はわからない（`RB-1998-ED4`）。
2. **エラッタの適用の開始**: エネルギー回収・超エネルギー回収は、会報 Vol.5（1998年6月10日発行）の告知を確認したが、古いカードへの適用開始日は未確認。プラスパワーとリザードンは、第1弾の版も新しい文面で使うことを『ポケモンカードオフィシャルブック2000』（2000年2月）で確認したが、それより前の告知と、使い始めた時期は未確認（`ERR-PLUSPOWER`・`TXT-CHARIZARD`）。
3. **発売日の食い違い**: 『めざせ! ポケモンカードマスター』の年表 [P34] と Bulbapedia で、化石の秘密（6月20日／6月21日）と拡張シート第2弾（7月17日／6月17日）の発売日が違う。第三の資料が必要です。
4. **混合期の扱いの範囲**: 大会のルールとして確認した読み替え（エネルギー・リムーブ、超エネルギーリムーブ、特殊状態と特殊能力など）が、ふだんの対戦にも及んだか。
5. **英語版のルールの原文**: WotC のルールブックはどれも原文を読めていない。
6. **カードの裁定の未解決の論点**: kyuura-engine の v0.68 までの記録を取り込み、『ポケモンカードオフィシャルブック2000』では決められない論点が 71 件ある（v0.26〜v0.68 で加えた 47 件は、トレーナー・特殊能力を対象のないときに使えるか・「最大N枚」で 0 枚を選べるか・レインボーエネルギーを「X」エネルギーとして扱うか・へんしん・ばける・思い出させる・退化・ワザの途中の入れ替え・ESP など）（同時のきぜつ・1 つのワザで複数回はたらく効果・あまごいでつけた枚数・だつりょくえき 4 件・「ダメージを与えた後」の効果・特殊能力のダメージの弱点と抵抗力など）。どの論点も、当時の公式の Q&A・大会の裁定・雑誌の記事は探していない。エンジンの停止コードは公式の裁定ではない（[カードの裁定と公式の最新の説明](rules/card-rulings.md) の 5 章・8 章）。
7. **日本語の効果文の照合**: 効果文は転記によるもので、英語版や画像と 1 枚ずつ照合していない。『ポケモンカードオフィシャルブック2000』で照合したカードで、転記の誤りが 1 件（ベロリンガのワザ名・レベル。直した）と、誤りの候補が 4 件（フシギソウ・ケーシィ、エンジンの照合の記録の取り込みでポニータ・タマタマ。印刷の版の違いかを確かめていないので直していない）見つかった。ガルーラのこどものおつかいの転記の誤りは、利用者が示した実物のカードの画像で直した（2026-10-19。`data/curation/card_corrections.json`）。ドードーのみだれづきの文面は、この本の図版の版が決まらないので調査課題にした。`jp_print.series` が空のカードが 50 枚ある（どの書き方の値を入れるかが決まっていない）。無色2個エネルギーの効果文と、ベイビィ・アンノーンのルール文が欠けている。日英の違いの記録のうち 5 件は有力のまま（文面の解釈が二次資料によるもの、英語版の表記・誤植、収録先）。

ほかの未確認の点は、[出典と確認状況](sources.md#まだ確認できていないこと)、[拡張パック以外の商品](cards/other-products.md#まだ確認できていないこと)、`data/rule_history.json` の `open_questions` にあります。

## 5. 次に取り組むこと

1. 未解決の論点 71 件について、kyuura が持つ当時のスキャン（『トレーナーズ』・会報）と公式サイトの Q&A の写しで、カードの Q&A・裁定を探す。結果に影響する論点（`audit.game_effect` が `game_result` の 62 件）を先にする（[カードの裁定と公式の最新の説明](rules/card-rulings.md) の 5 章）。
2. データの誤りの候補 4 件（フシギソウ・ケーシィ・ポニータ・タマタマ）と訂正の候補（`data/curation/card_corrections.json` の `candidates`。わるいカメックスのハイドロキャノンの 1 文字の脱落の疑いなど）と、ドードーのみだれづきの文面が、印刷の版の違いでないかを確かめてから直す。`jp_print.series` が空の 50 枚は、どの書き方の値を入れるかを決めてから、出典の別の記録で埋める（推測で埋めない）。
