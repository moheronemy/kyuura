# 調査の状況

この資料集で、どの分野をどこまで確かめられたかをまとめたページです。個々の記述の根拠は、各ページの出典の記号と確度（**確実**／**有力**／**未確認**）で示しています。このページはその集計と、まだ足りないものの一覧です。

- 資料があること、資料を読めたこと、その資料が特定の記述を裏付けることは、別のこととして扱っています。資料ごとの読めた範囲は [出典と確認状況](sources.md#調べ方について)、当時の印刷物のページごとの記録は [印刷物の照合記録](printed-sources.md) にあります。
- 数は `python3 scripts/research_stats.py` の出力を写したものです（[数えた時点](#数えた時点)）。データに項目として記録されていることだけを数えています。分母がはっきりしないものには割合を付けていません。
- 検証スクリプトが正常に終わることは、データの形と参照の整合を示すだけです。歴史的な内容がすべて正しいことを示すものではありません。

## 3. 主な未解決の問題

1. **ルール文書の本文**: 第1〜5版のルールブック・遊びかた説明書を、どの版も読めていない。版の比較表で、版の文書を根拠にしたマスは 0 です。
2. **エラッタの適用の開始**: エネルギー回収・超エネルギー回収は、会報 Vol.5（1998年6月10日発行）の告知を確認したが、古いカードへの適用開始日は未確認。プラスパワーとリザードンは、第1弾の版も新しい文面で使うことを『ポケモンカードオフィシャルブック2000』（2000年2月）で確認したが、それより前の告知と、使い始めた時期は未確認（`ERR-PLUSPOWER`・`TXT-CHARIZARD`）。
3. **発売日の食い違い**: 『めざせ! ポケモンカードマスター』の年表 [P34] と Bulbapedia で、化石の秘密（6月20日／6月21日）と拡張シート第2弾（7月17日／6月17日）の発売日が違う。第三の資料が必要です。
4. **混合期の扱いの範囲**: 大会のルールとして確認した読み替え（エネルギー・リムーブ、超エネルギーリムーブ、特殊状態と特殊能力など）が、ふだんの対戦にも及んだか。
5. **英語版のルールの原文**: WotC のルールブックはどれも原文を読めていない。
6. **日本語の効果文の照合**: 効果文は転記によるもので、英語版や画像と 1 枚ずつ照合していない。無色2個エネルギーの効果文と、ベイビィ・アンノーンのルール文が欠けている。日英の違いの記録のうち 5 件は有力のまま（文面の解釈が二次資料によるもの、英語版の表記・誤植、収録先）。

ほかの未確認の点は、[出典と確認状況](sources.md#まだ確認できていないこと)、[拡張パック以外の商品](cards/other-products.md#まだ確認できていないこと)、`data/rule_history.json` の `open_questions` にあります。
